Privacy

Every payment is public. What your agent asked and got back is not. This page lists what Siro keeps, for how long, and the code that does it.

What Siro keeps about a paid call
KeptWhat and why
Public, for good

The payment: tool, network, paying address, amount, transaction hash, run time, and the result's sha256, size and kind. The transfer is on-chain anyway; Activity shows the same rows so anyone can check them. The sha256 lets you prove which result you were sold without showing it.
Not kept

Your input: the prompt, the text, the URL or the address you sent. It goes to the tool, the tool answers, and Siro writes none of it to its database or its logs.
Not kept

Text and data results: answers from language models, prices, balances, pages read. They go back in the response and nowhere else.
7 days

Generated images, video and audio. Siro copies the file to its own storage under a random link, because the model host deletes its copy within an hour. After 7 days the link stops working and the storage deletes the file. The wallet that paid can delete it sooner: Delete it now under the receipt on a tool page, or the API below.
Your browser only

Ask chats and the Budget key live in this browser's storage. Siro's server sees each message only while it answers it.
Public, by choice

Calls paid by Siro's own two wallets (0x7787…70ad and 0xa6f3…ba17) are tests and demos. Their full results are public at /api/proofs as proof of what a paid call returns. No one else's are.
Up to 1 day

Rate limits for Ask, search, the relay and Sell a tool count requests per place. The counter stores a SHA-256 hash of the IP address and the time window, never the address itself, and is swept after the window ends.
Per day

$SIRO holders' free runs: the wallet address and how many free runs it used that UTC day.

Who else sees a call

Services that process a call
The model host

Premium models run on Replicate, which deletes the input and output of API predictions after an hour. The other models run on Cloudflare Workers AI. Each host's own terms apply to the call it runs.

A seller

Tools listed through Sell a tool run on the seller's own server, which receives your input. Its listing names the host.

The payment rail

Payments settle through the x402 facilitator for that network (Coinbase CDP, or HeyElsa's where CDP does not run), which sees the payment, not the input.

Anyone

The payment itself is a public transfer on its chain. Siro does not hide who paid.

Delete a result

Sign this text with the wallet that paid, with the transaction hash from your receipt in lower case:

Delete my Siro result
Transaction: 0x…

Then send the signature:

curl -X POST https://siroagent.com/v1/results/<tx>/forget \
  -H 'content-type: application/json' \
  -d '{"signature":"0x…"}'

The stored file is deleted and the row is marked deleted. The payment and its sha256 stay on the ledger. EVM wallets sign with personal_sign; Solana wallets sign the same text with ed25519 and send it in base58.

Calls before 27 Nov 2026 did not record which file they made, so they cannot be deleted this way; their files expire on the 7-day rule like every other.

Where this is in the code

The 7-day rule and the delete text: shared/privacy.ts. The media copy and its expiry: worker/premium.ts and the /media/ route in worker/index.ts. The payment row: worker/proof.ts. Deleting: POST /v1/results/:tx/forget in worker/v1.ts.
