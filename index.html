Three ways in. One price list.

Plain HTTP, the siro CLI and an MCP server all price from the same catalog file, so a tool costs the same wherever your agent calls it.

for prediction-read

HTTP

curl -i -X POST https://siroagent.com/v1/prediction-read \
  -H 'content-type: application/json' \
  -d '{"market":"fed interest rates"}'

The 402 puts the price in the payment-required header. Sign accepts[].amount for one network, send the same request again with a payment-signature header, and the result comes back with a receipt.

CLI

npm i -g https://siroagent.com/cli/siro.tgz
siro init
siro limits --per-payment 0.10 --per-day 1
siro call prediction-read market='fed interest rates'

siro init makes a key and encrypts it with your password. siro limits sets the caps the CLI checks before it signs anything.

MCP

{
  "mcpServers": {
    "siro": {
      "command": "siro",
      "args": [
        "mcp"
      ],
      "env": {
        "SIRO_PASSWORD": "your wallet password"
      }
    }
  }
}

For Claude, Cursor or any MCP client. The local server runs on the CLI wallet and pays inside its caps. Remote, with nothing to install: https://siroagent.com/mcp lists the catalog for free, and its siro_call answers with the 402 terms until your client signs.
