Every tool is one POST.

Each of Siro's 67 tools is an HTTP endpoint that charges per call with x402 v2. There are no accounts and no API keys: an unpaid request gets the price, a signed one gets the result.

How x402 pays for a call

Go to the live check for How x402 pays for a call
Live check · unpaid request

POST /v1/gas-now

This check runs from your browser against siroagent.com and never signs a payment.

  1. You ask. Send POST /v1/<id> with your JSON input and no payment. A tool that is switched on answers 402 Payment Required with a quote. If the input is wrong, the quote also carries inputError, and a client should stop there.
  2. Siro quotes. The body, and the same JSON base64-encoded in the PAYMENT-REQUIRED header, lists accepts: one entry for each network that can be paid right now. Each has scheme: "exact", network as CAIP-2, amount in 6-decimal base units, asset, payTo, maxTimeoutSeconds (120, or 300 for tools that run for minutes) and extra: the token's EIP-712 name and version, or the facilitator's feePayer on Solana.
  3. You sign. On an EVM chain, sign an EIP-3009 TransferWithAuthorization for exactly amount to payTo; signing costs no gas. On Solana, sign a USDC transfer with the quote's feePayer as fee payer. Send the x402 v2 payload base64-encoded in PAYMENT-SIGNATURE (the older X-PAYMENT header also works), with the entry you picked in accepted. An EVM payment that names no network is taken as Robinhood Chain.
  4. The tool runs, then the money moves. The facilitator verifies the signature, the tool runs, and the transfer settles only once the result is ready. The response carries result, a receipt with network, asset, amountUsd, payer, tx, ms and resultSha256 (the sha256 of JSON.stringify(result), which Activity lists next to the payment so you can check the result you got is the one recorded), and a base64 PAYMENT-RESPONSE header with the transaction hash. One signed authorization pays for one call.

The 402 lists only the networks that can be paid right now, with Base first because many x402 clients take the first entry. Ask, Budget, the CLI and the SDK still pay on Robinhood Chain unless you pick another.

Tools that run for minutes (video and the longer music tracks) are quoted on the EVM chains only, with a 300-second window. The catalog marks each one. A signed Solana transaction expires in about a minute, before a render would finish.

On Solana the payment payload is { transaction }: a v0 transaction with SetComputeUnitLimit, SetComputeUnitPrice, a USDC TransferChecked and a Memo, signed by you, with the quote's extra.feePayer as fee payer and its signature slot left empty for the facilitator. The fee payer can change from one quote to the next, so read it from each one.

Endpoints

Live check · live totals

GET /api/stats

This check runs from your browser against siroagent.com and never signs a payment.

Base URL https://siroagent.com. Every /v1 route allows cross-origin calls and exposes the PAYMENT-REQUIRED and PAYMENT-RESPONSE headers.

GET /v1/resources
Every tool: id, name, category, price, input fields, what it returns, the networks it is quoted on and whether it is live. Free.
GET /v1/resources/:id
One tool, same fields. Free.
POST /v1/:id
Run a tool. It answers 402 with a quote until a payment is attached.
GET /v1/payments?payer=
Settled payments for one 0x or Solana address, newest first, up to 200. Free.
GET /api/stats
Live totals: tools listed, networks quoting, paid calls, volume, payers and the last settlement. Free.
GET /api/ledger
Settlements newest first (50 by default, ?limit= up to 500), the totals for the whole table, and 30 days of daily totals: the data behind Activity. Each row carries its transaction and a result with the sha256, size and kind of what the call returned. Add ?before= with a Unix time to page back. Free.
POST /v1/llm-auto
Cheapest Model. Send prompt and, if you like, tier (fast, balanced or frontier), maker (one company, or open-weight) and max_price. Siro picks the cheapest language model in the catalog that fits; the 402 quote is that model's price and carries a picked block naming it, so your agent sees the model before it signs. The result repeats the pick and the most expensive model that also fitted. The tiers group the models by how each maker positions them; the table is shared/router.ts. Add a check and Siro holds the answer to it: must_include (phrases, comma-separated), min_chars, json (yes) or json_keys. An answer that fails is retried on the next model up the same tier and maker, at most twice, at Siro's cost: you pay the quoted price of the first model and nothing more. If no answer passes, the call fails with no_answer_passed and your payment is not settled. The result's check.attempts lists every model tried, whether it passed, why not, and who paid for it. Siro spends at most $3 a day on retries across all callers; past that, a failed answer is not retried.
GET /api/holder/<address>
The wallet's $SIRO balance on Robinhood Chain, its tier (1,000,000 $SIRO: 25% off every tool and 10 free data runs a day; 10,000,000: 50% off and 30), and the free runs left today. To pay the holder price, send x-siro-holder: <address> with the call; the 402 quote then carries the lower amount and a holder block, and the payment must come from that address. For a free run of a data tool, send x-siro-pass: <address>.<expires>.<signature>, a personal_sign of Siro holder pass\nAddress: <lowercase address>\nExpires: <unix seconds>, valid up to 24 hours. Free.
GET /api/proofs
Calls paid by a Siro team wallet, each with the full result it returned; /api/proofs/<tx> for one. sha256 of JSON.stringify(result) equals the row's resultSha. Free.
GET /api/discover?q=
Third-party x402 services from the x402 Bazaar index, payable ones first. limit goes up to 20, and one IP address can search 120 times an hour. Free.
GET /api/tokens?network=
The tokens your agent can swap on robinhood or base, with every Robinhood stock token. Free.
POST /mcp
The remote MCP server. See MCP server.

Errors and charges

Go to the live check for Errors and charges
Live check · bad input

POST /v1/gas-now

This check runs from your browser against siroagent.com and never signs a payment.

There are no refunds, because a call that fails is never settled. The tool runs after the facilitator verifies your signature and before the transfer settles. If the tool, the model or the link you gave fails, the authorization is never executed and its nonce is released, so you can sign again.

Input errors are caught before any payment is verified. Without a payment, a bad input still gets the 402 quote, with the problem in inputError; Siro's own clients stop there and sign nothing. With a payment attached, the input error comes back with its HTTP status and nothing is charged.

One case returns the result before the money has landed. When the transfer was broadcast but is not confirmed yet, you get the result and a receipt with status: "pending" and the transaction hash. The transfer is already on its way, so the result is not held back.

Tool and input errors come back with their HTTP status and the first body below. Payment errors are a 402 with the second.

400 missing_field, invalid_field, invalid_url, invalid_network, invalid_address, invalid_body, invalid_json
Your input. Never charged.
413 field_too_long, body_too_large, too_large
Too long or too big. Never charged.
404 not_found
No tool with that id.
402 invalid_payment
The payment header could not be read, or it does not match the quote: amount, payTo, network or asset.
402 verify_invalid
The facilitator refused the signature (balance, amount or expiry) or could not be reached.
402 nonce_used
That authorization was already used. Sign a new one.
402 settle_failed
The transfer did not go through after the tool ran. You get no result and pay nothing, and the nonce is released.
404 market_not_found, stock_not_found, not_a_contract
Nothing was found for that input. Not charged.
422 fetch_failed, not_an_image, model_refused
The link or the prompt could not be used. Not charged.
429 model_busy
The model is at capacity. Retry in a few seconds. Not charged.
502 model_failed, empty_answer, no_price, resource_failed, *_unavailable
Something upstream failed. Not charged.
503 payments_not_configured, not_live
Payments, or this tool, are not switched on. Not charged.
504 render_timeout
The model took too long and the job was cancelled. Not charged.

What Siro keeps

Every payment is public: the tool, network, payer, amount, transaction hash and the result's resultSha256 are on Activity, as the transfer is on-chain. Your input and text or data results are not stored. Generated images, video and audio are served from /media/ for 7 days, then refused and deleted; the result carries expiresAt.

The wallet that paid can delete a stored file sooner. Sign Delete my Siro result\nTransaction: <tx in lower case> and send POST /v1/results/<tx>/forget with {"signature":"…"}. The payment row and its sha256 stay. The full list is on Privacy.

The agent wallet

Go to the live check for The agent wallet
Live check · this browser

localStorage

This check reads this browser's storage and never shows the key.

Budget makes a key in your browser and keeps it in this browser's localStorage, unencrypted. Anyone who can open this browser profile can read it. Export a backup there, and keep only a small balance on it.

Siro's servers never receive the key: the browser signs each payment itself and sends only the signed authorization. Before it signs, it checks the price against your caps, per payment and per day, with EVM and Solana spending counted together. Swaps have their own per-swap cap. A new wallet starts at $0.10 per payment, $1.00 per day and $25.00 per swap, with autopay off, so Ask waits for your yes on every payment.

The same key has a Solana address, derived from it, so one backup covers both. A connected wallet such as MetaMask or Rabby can pay instead; it asks in its own window every time and pays on the EVM chains only.

The CLI works differently: it encrypts its key with your password, using scrypt and AES-256-GCM, in ~/.siro/keystore.json.

Siro keeps these entries in this browser's localStorage:

siro.agent.key
The private key, as plain hex text.
siro.agent.limits
Your caps and the autopay switch.
siro.agent.log
The last 500 payments and swaps made in this browser. The daily cap counts from it.
siro.network
The payment network you picked last in Ask or Tools. Robinhood Chain until you pick another.

CLI

The CLI, SDK and local MCP server are open source in siroagent/siro, next to the Worker and the site.

Live check · the package

GET /cli/siro.tgz

This check runs from your browser against siroagent.com and never signs a payment.

The siro command keeps the agent key on your machine, encrypted with your password, and checks the same caps before it signs anything.

Every payment and swap asks for confirmation unless you add --yes; the caps apply either way. --network base, solana, arbitrum or polygon pays in USDC on that network instead of USDG on Robinhood Chain. Swaps run on robinhood or base. Set SIRO_PASSWORD for scripts and for siro mcp.

The wallet also has a Solana address, derived from the same key. siro export-key --solana prints that key in the form Phantom and Solflare import. Files live in ~/.siro, or wherever SIRO_HOME points: keystore.json, config.json for caps and network, and spend.jsonl for history.

Remote, nothing to install

https://siroagent.com/mcp speaks Streamable HTTP with JSON responses and needs no key. Browsing is free: siro_resources, siro_resource_schema, siro_discover and siro_tokens. siro_call runs a paid tool when params._meta["x402/payment"] carries a signed x402 payment. Without one it returns isError with the payment requirements to sign, and a paid call returns its receipt in _meta["x402/payment-response"]. Paying x402 services outside Siro

Go to the live check for Paying x402 services outside Siro
Live check · x402 index search

GET /api/discover

This check runs from your browser against siroagent.com and never signs a payment.

Beyond its own catalog, Siro searches the open x402 Bazaar index, run by Coinbase CDP, and pays any service that takes the exact scheme in USDG on Robinhood Chain or USDC on Base, Solana, Arbitrum or Polygon. Ask does this when no Siro tool fits: it finds a service, fills in its input and shows you the price before paying.

Their owners run these services, not Siro, so their answers, prices and refund rules are theirs. In the browser, calls go through a narrow relay, POST /api/relay, that forwards only to services discovery returned and never sees your key. The CLI, the SDK and the MCP server call them directly.

Swaps

Go to the live check for Swaps
Live check · swappable tokens

GET /api/tokens

This check runs from your browser against siroagent.com and never signs a payment.

Swaps route through the KyberSwap aggregator on Robinhood Chain and Base, Robinhood stock tokens included. The quote and the transaction are built on your device and sent from your wallet: an approval for the exact amount when one is needed, then the swap, with 1% maximum slippage by default. A swap needs a little ETH for gas. Siro adds no fee.

Ask always asks before it sends a swap, the CLI asks unless you add --yes, and the local MCP server swaps only after siro limits --mcp-swaps on. A swap from an agent wallet (Budget, the CLI, the SDK or the local MCP server) is held to the per-swap cap, $25.00 for a new wallet. A connected wallet asks in its own window instead.
