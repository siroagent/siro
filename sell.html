Sell a tool

List your HTTPS API at a price per call. Buyers pay your own address in USDG or USDC, and a payment settles only when your API returns a result. Siro takes no cut.

How it works

  1. Prove the host is yours.

    Publish /.well-known/siro.json on your API's host, naming the address that gets paid:

    { "payTo": "0xYourAddress" }
  2. Describe the tool.

    Name, price, endpoint and input fields. Siro sends one test call with your example input and the header x-siro-test: 1. It must answer with JSON.

  3. Keep the secret.

    Every call from Siro carries it as x-siro-secret; reject calls without it, so only paid calls get through. It is also the key to pause or remove the listing. Siro shows it once.

What your API receives

Request
POST to your endpoint, a JSON body with the fields you define, already checked against them.
Headers
x-siro-secret, x-siro-payer (the buyer's address) and x-siro-network.
Answer
A 2xx JSON response within 60 seconds, 1 MB at most. That is the result the buyer gets.
Money
The buyer signs a transfer to your address for the exact price. It settles after your answer, on Robinhood Chain (USDG) or Base, Arbitrum or Polygon (USDC). Nothing passes through Siro.
Failures
An error, a timeout or a non-JSON answer is not charged. Five failures in a row pause the listing until you resume it.
